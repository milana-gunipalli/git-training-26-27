# Git Training 26–27

1. Get into pairs. If you have less experience, go with someone with more experience.
2. Open VS Code. Use **Clone Repository** to clone this repo, then open it.
3. Create a branch: `practice/pair01`. Use a different pair number if taken.
4. Copy `practice/TEMPLATE.md` to `practice/pair01.md`. Use your pair number and answer the questions.
5. In Source Control, review your diff, stage your file, commit, and push. Use **Publish Branch** for the first push.
6. On GitHub, open a PR: base `main`, compare your branch. Have another pair review it and suggest a small change. Edit, stage, commit, and push that change on the same branch.
7. After I merge your PR, go back to VS Code. Switch to `main` and pull.
